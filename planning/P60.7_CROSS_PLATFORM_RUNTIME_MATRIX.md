## Findings
1. **Backend code is OS-portable** (no hardcoded Windows paths, path.join, env ports). Verified by grep (no `C:\` in backend/src).
2. **`_tools/*.cmd` launchers are Windows-only.** Linux needs systemd units / npm scripts (documented gap).
3. **PostgreSQL is native (NOT Docker)** by P58 design; Docker PG exists as alternative but is not the runtime.
4. **Cross-platform claims: Windows VERIFIED (runtime), Linux AUDITED (code-portable, not runtime-tested).** NOT claimed as Linux-certified.
