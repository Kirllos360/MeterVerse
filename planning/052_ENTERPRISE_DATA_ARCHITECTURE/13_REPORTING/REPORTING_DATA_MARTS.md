# Enterprise Reporting Data Marts

**Part of P11 Enterprise Data Architecture**

## Data Marts
| Data Mart | Source | Purpose | Refresh |
|-----------|--------|---------|---------|
| Operational Data Mart | ODS | Daily operations monitoring | Real-time |
| Financial Data Mart | GL, Journal, Ledger | Financial reporting | Daily |
| Customer Data Mart | Customer, Contract, Billing | Customer analytics | Daily |
| Meter Data Mart | Meter, Reading, Events | Meter performance | Real-time |
| AI Data Mart | AI Memory, Knowledge, Feedback | AI model monitoring | Hourly |
| Analytics Data Mart | All sources | Cross-domain analytics | Hourly |
| Executive Data Mart | All data marts | Executive dashboard | Daily |
