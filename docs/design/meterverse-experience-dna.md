# MeterVerse Experience DNA

## Brand Personality
- **Enterprise** — Trustworthy, robust, no gimmicks
- **Utility** — Purpose-built for critical infrastructure
- **Energy** — Dynamic, alive, responsive
- **Reliability** — 99.9% uptime feel, predictable
- **Intelligence** — AI-augmented, not AI-replaced

## Layout Philosophy
- **Information density**: Moderate — less is more, but power users can enable dense mode
- **Breathing room**: 24px base padding, 16px card padding, 8px between related items
- **Hierarchy**: Sidebar (navigation) → Main (content) → Context Dock (actions/insights)
- **Progressive disclosure**: Show essentials first, nest advanced options

## Design Principles
1. **Clarity over creativity** — Every pixel has purpose
2. **Consistency over novelty** — Follow patterns users already know
3. **Performance over features** — 50ms response or it feels broken
4. **Accessibility over aesthetics** — WCAG 2.2 AA minimum

## States Philosophy
- **Loading**: Skeleton shimmer (not spinners) — shows structure before content
- **Empty**: Illustration + action — guide users, don't leave them staring at blank space
- **Error**: Actionable message — what happened, why, what to do next
- **Success**: Subtle confirmation — toast, not modal
