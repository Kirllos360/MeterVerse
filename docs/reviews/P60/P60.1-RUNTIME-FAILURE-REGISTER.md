## Failures Investigated in This Gate

### F1. PostgreSQL :5433 down (environmental — BLOCKED)
- **ERROR:** `psql: connection refused (0x0000274D)`; pg_ctl `server process terminated by exception 0xC0000142`; empty startup logs.
- **SOURCE:** Windows environment (8GB RAM), NOT application code.
- **FIRST OBSERVED:** 17:18 (first prisma DB failure in backend.log), persisted.
- **REPRODUCIBLE:** YES (every start attempt under 1MB free RAM).
- **ROOT CAUSE:** 8GB RAM exhausted — Free=1MB, Memory Compression ~1090MB, Edge ~1300MB, OpenCode host ~1075MB, Defender 228MB. PostgreSQL child cannot allocate/init DLLs.
- **AFFECTED COMPONENT:** all DB-dependent runtime (login, CRUD, browser workflows).
- **DEPENDENCIES:** none (environment).
- **FIX:** require freed RAM (close browser tabs / restart) + elevated `net start postgresql` (PG16 :5433). Not possible from non-admin tool shell.
- **TEST:** attempted pg_ctl ×6, net start ×1 — all fail under memory pressure.
- **REGRESSION RESULT:** n/a (blocked). Data verified INTACT (pg recovery completed earlier, WAL present, 6 base dirs).

### F2. Boot.cmd wrong PG service hint (FIXED)
- **ERROR:** line 19 suggested `net start postgresql-x64-18` for the :5433 DB.
- **SOURCE:** _tools/Boot.cmd.
- **ROOT CAUSE:** service `postgresql-x64-18` is PostgreSQL **18** on `C:\Program Files\PostgreSQL\18\data`, port **5434** (verified postgresql.conf). MeterVerse DB :5433 is PG **16** service `postgresql` (verified: PG16 data dir, port 5433).
- **FIX:** line 19 → `net start postgresql` + explanatory comment. APPLIED.
- **TEST:** file parses; comment reflects verified fact.
- **REGRESSION:** no tool behavior change beyond the corrected hint.
