**WHICH TARIFF?**
A solar tariff with 12 tiers (0.48 → 1.58 EGP/kWh, over 1000 kWh = 1.68) + 2% admin fee + 9.10 EGP service fee. This is the exact formula used by the original Collection System — verified, not guessed.

**HOW DOES A READING GET LINKED TO A METER?**
Every reading stores the meter's unique ID (`Reading.meterId → Meter.id`). A reading belongs to meter 52051449 because that's the meter's ID in the reading's row. The meter is found by its serial number `52051449`.

**HOW IS A BILL CALCULATED?**
`consumption = import register − previous import register`. The tariff converts kWh into money, then + 2% admin + 9.10 service = the invoice total.
